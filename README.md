# LeeOS Escape Room

Ein statischer Escape Room im TempleOS-Stil fuer den Informatikunterricht.

## Start

Die Webseite kann direkt ueber `index.html` geoeffnet werden. Alle benoetigten Medien liegen im Ordner `assets/`.

## Debug

Der Debug-Modus kann in der Kopfzeile mit dem Passwort `blumdebug` aktiviert werden.

## Deployment

Das Projekt ist statisch und kann auf jedem Webserver oder via GitHub Pages ausgeliefert werden.
